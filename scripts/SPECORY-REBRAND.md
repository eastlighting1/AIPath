# SPECORY brand rollout

Applied: public site names and titles, bilingual navigation and notices, wordmark and favicon, twelve hexagonal credential badges, tier-colored rectangular learning cards, About art, exam/result screens, report PNG generation and share-page metadata.

Palette: Deep Ink #142427, Teal #29B3A7, Off White #F7F9F8, Slate #8A9A9A. Darker teal/slate are used for readable text. Credential tiers: green, blue, purple, gold.

Existing origin, project ID, curriculum/lesson IDs, browser storage keys, exam API headers and historical result images are retained for compatibility. Historical shared PNGs are immutable; new reports use SPECORY.

Brand SVGs are scalable adaptations of the supplied folded document/check symbol and badge references. Lesson headings remain live accessible text. No new example course from the reference was added.
